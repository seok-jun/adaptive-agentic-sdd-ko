## 승인·허가

- 설계 승인: 필요한 경우 단계 / 대상 / 결정 범위 / 승인자 / 시간:
- 최종 통합: 후보 / 요청 행위 / 사람의 명시적 승인 기록:
- 또는 적용 가능한 저위험 위임: 정책 참조와 적용 조건 충족 여부:

구현·설계 승인은 병합·작업 종료·릴리스 승인이 아닙니다. Reviewer PASS가 사람의 승인을 만들지 않습니다. 실제 승인 전까지 최종 권한은 대기 상태로 둡니다.

## 위험·문서·준비 상태

- 위험과 롤백 점검 대상:
- 지속 문서 갱신 내용 또는 불필요한 이유:
- 미해결 제한 사항·필수 차단 사항:
- 상태: 차단 / Human Review 준비 완료 / 기록된 행위에 대해 허가됨.

허가된 행위가 실제 수행되기 전에는 통합·종료·릴리스 완료로 표시하지 않습니다. 중요한 변경 후 영향받는 증거·검토·승인을 재확인합니다.
