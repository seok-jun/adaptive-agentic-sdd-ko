# AGENTS.md — Starter

항상 적용하는 보호 규칙과 라우팅만 이 파일에 두고 작게 유지합니다. 절차는 Skill·로컬 계약에 둡니다. 도입 전에 placeholder를 바꾸고 관련 없는 예시를 제거합니다.

## 시작 순서

1. 변경되지 않았다면 실행당 한 번 이 파일을 읽습니다.
2. 현재 작업 항목 또는 신뢰할 수 있는 최신 스냅샷을 읽습니다.
3. 구현은 `.agents/skills/implementing-issue/SKILL.md`로 연결합니다.
4. 작업에 필요한 경우에만 상세 절차·도메인 문서를 읽습니다.
5. 리비전과 관련성이 유지되는 동안에만 문맥을 재사용합니다.

## 항상 적용하는 보호 규칙

- 관련 없는 사용자·팀 변경을 보존하며 reset·clean·revert·덮어쓰기를 하지 않습니다.
- 파일, API, 명령, 스키마, 라벨, 아키텍처 규칙을 지어내지 않습니다.
- 수정 허용·금지 경계를 지킵니다. 직접 의존 관계를 읽는 것이 범위 밖 수정 허가는 아닙니다.
- 관련 없는 정리, 리팩터링, 업그레이드, 기능을 작업 항목에 섞지 않습니다.
- 필수 의존성, 권한, 소유권, 범위가 해결되지 않으면 수정을 멈춥니다.
- 미실행 검사를 PASS로, 자체 검토를 독립 검토로 보고하지 않습니다.
- 계획·구현·커밋 승인은 병합·작업 종료·릴리스 승인이 아닙니다.
- 비밀정보, 비공개 조직·고객 정보, 민감 데이터를 커밋·공개 작업 항목·PR·로그에 넣지 않습니다.

## 작업 라우팅

| 작업 | 로컬 기준 경로 |
| --- | --- |
| 승인된 작업 항목 구현 | `.agents/skills/implementing-issue/SKILL.md` |
| 등급·검토·승인·증거의 의미 | `docs/sdd-workflow.md` |

실제 사용으로 필요성이 확인될 때만 Skill을 추가합니다. 로컬 계약은 도입 스냅샷이며 업그레이드는 명시적으로 조정합니다.

## 프로젝트 불변 조건

`<module A>`가 `<module B>`에 의존해서는 안 된다는 규칙, 생성·공유 경로의 명시적 소유권, 확인된 빌드 명령 참조처럼 안정적이고 가치가 큰 사실만 추가합니다. 이 placeholder는 실제 저장소 사실이 아닙니다.

## 컨텍스트 효율

직접 경로·심볼과 제한된 전달 자료를 우선합니다. 성공은 요약하고 실패·불확실성은 드러내며 증거 참조를 보존합니다. 토큰 절약을 위해 필수 검증·검토·허가를 제거하지 않습니다.
