# 워크플로 도식

- `workflow-overview-ko.svg`: 간결한 생명주기와 등급별 준비 과정.
- `workflow-detailed-ko.svg`: 순서가 있는 게이트, 증거 차단 조건, 선택적 Blind Audit, 최종 허가.
- `workflow-ko.svg`: 기존 링크를 위한 호환 경로. 최신 상세도와 내용이 같아야 합니다.

SVG는 수정 가능한 텍스트 원본이며 외부 폰트·이미지·스크립트·원격 리소스를 포함하지 않습니다. 독립 파일로도 읽을 수 있게 유지하고 텍스트 선택이 가능해야 합니다. PNG 미리보기는 선택적 열람 산출물이지 별도의 정책 원본이 아닙니다.

기준 의미는 `../docs/workflow.md`, `../docs/risk-grades.md`, `../docs/review-gates.md`, `../docs/verification.md`에 있습니다. 의미가 바뀌면 두 도식과 README 설명을 함께 갱신합니다.

XML 유효성, 로컬 링크, 렌더링 가독성과 다음 의미를 확인합니다. 간결한 경로는 불필요한 설계 검토를 생략합니다. Large는 AS-IS와 PLAN을 구분합니다. Blind Audit은 선택 사항입니다. 필수 증거·검토 미충족은 통합을 차단합니다. 최종 허가는 설계 승인과 별개입니다. XML·렌더링 검사는 런타임이나 독립 검토 증거가 아닙니다.

영문 도식과 단계·연결선·필수 및 선택 조건의 의미를 동일하게 유지합니다. 호환 경로의 SVG도 상세도와 함께 갱신합니다.
