# Trivial 예시

**가상 변경:** 실행 예시, 요구사항, 워크플로 의미를 바꾸지 않고 설명 문장의 오탈자를 수정합니다.

직접 대상이 좁고 정적 비교와 형식·링크 확인으로 요청을 입증할 수 있습니다. 런타임, 빌드, 테스트, 스키마, 의존성, API, 에이전트 실행 의미가 바뀌지 않습니다.

간단한 작업 항목을 작성하고 수정한 뒤 관련 정적 검사와 diff 자체 검토를 수행합니다. 실제 확인한 것을 기록하며 기본적으로 별도 SDD 패키지나 독립 검토는 필요하지 않습니다. 최종 후보에 대한 사람의 허가를 받거나 적용 가능한 명시적 저위험 통합 위임을 기록합니다.

런타임 테스트를 실행하지 않았다면 PASS라고 보고하지 않습니다. 이는 진행 예시이지 실행 증거가 아닙니다.

**반례:** Markdown 규칙을 “승인을 기다린다”에서 “자동으로 병합한다”로 바꾸면 실행 의미가 바뀌므로 Trivial이 아닙니다. 수정 전에 위험에 따라 재분류합니다.
