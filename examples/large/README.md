# Large 예시

**변경:** 외부 유료 작업을 실행하기 전에 재시도 예산을 집행하는 로직을 추가합니다.

Large인 이유:

- 재시도 동작
- 비용 노출
- 실패 영향

절차:

1. AS-IS에서 재시도 책임 주체와 외부 호출 경계를 확인합니다.
2. 설계 검토에서 유료 호출 전에 예산을 집행할 수 있는지 확인합니다.
3. TO-BE에서 재시도 순번 입력, 누적 비용 입력, 허용·차단 결정, 실패 동작을 정의합니다.
4. 검증 전략에서 한도 직전·한도 도달·한도 초과, 재시도 누적, 유료 작업 전 집행을 입증합니다.
5. 실제로 경쟁하는 책임 배치 선택지가 있을 때만 트레이드오프를 기록합니다.
6. 설계 게이트를 통과한 후 구현합니다.
7. 독립 코드 검토에서 경계, 실행 순서, 증거를 확인합니다.
8. 통합 테스트로 실제 플랫폼 동작을 입증할 수 없는 경우에만 실기기·런타임 QA를 수행합니다.
