# Small 예시

**가상 변경:** 공유 계약이나 실패 비용이 큰 동작 변경 없이 하나의 소유 모듈 안에서 포맷 규칙을 조정합니다.

1. 작업 항목에 범위, 보존할 동작, AC를 정의합니다.
2. 제한된 AS-IS와 계획을 작업 항목에 기록하고 별도 SDD 패키지는 만들지 않습니다.
3. 소유 모듈과 직접 관련 테스트만 수정합니다.
4. 대상 테스트를 실행하고 AC별 실제 결과, 리비전, 증거를 기록합니다.
5. diff를 자체 검토합니다. 구체적 위험이 있으면 독립 검토를 선택합니다.
6. 최종 후보에 대한 사람의 명시적 통합 허가를 받거나 적용 가능한 저위험 사전 허가 정책을 기록합니다.
7. 필수 검사 통과 후 해당 권한 범위에서만 병합·종료합니다.

실제로 경쟁하는 선택지가 없다면 트레이드오프 섹션을 만들지 않습니다. 가상의 절차 예시이며 검사가 실행되었거나 승인이 있었다고 주장하지 않습니다.
